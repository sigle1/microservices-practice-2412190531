# 项目规划：宠安心

- **项目名称**：宠安心——宠物医院预约与诊疗管理系统
- **目标用户**：中小型宠物医院的宠物主人、前台工作人员、宠物医生与系统管理员。
- **优先业务场景**：单院区常规门诊预约。宠物主人先为宠物建档，再选择就诊时段提交预约；本周实现建档、创建预约和按宠物查询预约，暂不实现医生排班与签到。
- **核心模型**：`Pet`（宠物档案）与 `Appointment`（预约）。后续将围绕二者扩展主人、医生、排班、病历和账单等模型。

## 第 04 周：业务流程与规则

本周的核心流程为“注册宠物 → 创建门诊预约 → 查询该宠物的预约”。`Pet` 与 `Appointment` 是一对多关系：一只宠物可以有多条预约，而每条预约必须关联一只已经存在的宠物。预约创建由 Service 层负责；若同一宠物已经在同一 `appointmentTime` 有预约，则拒绝再次创建并返回冲突结果。该规则既避免前台重复登记，也由数据库的 `(pet_id, appointment_time)` 联合唯一约束进行保护。
