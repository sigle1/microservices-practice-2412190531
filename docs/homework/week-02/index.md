# 第 2 周作业：项目选题与功能规划

## 项目选题

### 最终选题

**项目名称：宠安心——宠物医院预约与诊疗管理系统。**

本项目面向中小型宠物医院，解决纸质登记、电话预约和分散表格带来的预约冲突、宠物历史信息缺失、病历难追溯和收费易遗漏等问题。系统的主要用户为宠物主人、前台工作人员、宠物医生和系统管理员：主人需要维护宠物档案并预约就诊，前台需要协调号源和收费，医生需要查询病史并完成诊疗记录，管理员需要维护基础数据和账号权限。

选择该题目的原因是其业务主线清晰且覆盖的领域足够丰富：宠物档案、预约排班、接诊病历与收费结算能够形成完整闭环；这些边界也适合后续逐步实践数据库持久化、认证授权、服务拆分、消息通知、分布式事务、监控和部署。首期以单院区常规门诊为边界，不处理真实支付、药品供应链、多院区调度等复杂外部场景，保证项目能够随课程节奏持续演进。

### 确定过程

在宠物医院、购物、图书借阅、健身房会员、餐厅点餐和二手交易等候选方向中进行比较后，确定选择宠物医院系统。相较于图书借阅和健身房场景，它的跨角色协作与状态流转更丰富；相较于购物和二手交易场景，它不依赖复杂的物流、支付平台和即时聊天等外部能力。预约、诊疗和收费三个核心领域既具有实际业务价值，也能自然映射为后续的服务边界。
